# 🔥 Na Łogniu — Flame Grill & Street Food Web Application

A modern, high-converting commercial web application designed for a authentic street food & flame grill restaurant (**Na Łogniu**), specializing in craft burgers, kebabs, and grilled meats.

## 🌟 Key Features

* **Dark Flame Visual Aesthetics:** Dark Charcoal (`#0F0F12`) design system combined with Flame Crimson (`#E63946`) and Gold accents (`#FFB703`).

* **Interactive Menu & Category Filtering:** Instant client-side filtering across core menu categories (*Burgers, Kebabs, Grill Specials, Chicken, Side Dishes*).

* **Detailed Product Modals:** Dynamic modal windows displaying precise ingredient lists, sauce options, and pricing breakdowns for each dish.

* **Click-to-Call Conversion UX:** Optimized mobile header and prominent floating action buttons for instant phone order placements.

* **Vector Iconography:** Clean, modern Font Awesome 6 icons replacing default web glyphs for a crisp commercial layout.

* **Mobile-First Responsive Layout:** Custom slide-out navigation menu, flexible CSS Grid cards, and zero horizontal scrolling on mobile devices.

## 🏗️ Project Architecture

```
na-logniu-website/

├── styles.css        # Custom CSS styles, design tokens & responsive breakpoints
├── script.js        # Dynamic menu database, category filtering & interactive modal scripts

```

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/na-logniu-restaurant.git
   ```

2. Navigate to the project directory:
   ```bash
   cd na-logniu-restaurant
   ```

3. Open `index.html` directly in your browser or run via VS Code Live Server.
